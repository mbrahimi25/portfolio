## Features

### Project System

- Modular project cards
- Conditional rendering of project metadata
- External links (GitHub, GitLab, live demos, documentation)

### Article System

- Dynamic routing using slugs
- Structured article pages
- Optional metadata sections such as tech stack visualization

### Component Architecture

- Navbar
- Footer
- Hero sections
- Reusable project cards
- Article layouts

### Animations

- Page-level transitions
- Scroll-based reveal effects
- Hover interactions on interactive elements
- Smooth motion using Framer Motion

## Skills Demonstrated

### Frontend Engineering

- Component-based architecture using React
- Next.js App Router structure
- Separation of server and client components

### Type Safety

- Strong TypeScript typing for components and data models
- Predictable and maintainable code structure

### UI / UX Design

- Responsive layouts using Tailwind CSS
- Consistent spacing system and typography hierarchy
- Minimal and modern interface design

### Routing & Architecture

- File-based routing system
- Dynamic routes for article pages
- Scalable project structure

### Performance Awareness

- Image optimization using Next.js Image component
- Static rendering where appropriate
- Efficient dependency usage
